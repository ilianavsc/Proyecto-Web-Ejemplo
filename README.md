# Proyecto-Web-Ejemplo

## Cómo clonar y ejecutar el proyecto
1. Clona el repositorio: `git clone https://github.com/ilianavsc/Proyecto-Web-Ejemplo.git`
2. Abre la carpeta en VS Code.
3. Haz doble clic en `index.html` para verlo en tu navegador.

## Ramas del proyecto
- `main`: Rama principal que contiene el proyecto base y la resolución del conflicto.
- `feature-mejora-estilo`: Rama donde se aplicaron las mejoras visuales en CSS.
